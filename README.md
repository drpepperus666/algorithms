прикладных задач». Каждая работа лежит в своей папке вместе с данными.

## ТК 1-2. Парная регрессия (гиперспектр кукурузы)

Задание: по файлу `Гиперспектр кукурузы.csv` построить зависимость
`Spectr` от `wavelength`. Аргумент масштабировать: `x = wavelength * 0.001
(иначе градиентный спуск расходится). Плюс нелинейная аппроксимация (парабола).

Что сделано:
1. Линейная регрессия аналитически (формулы МНК) + график.
2. Линейная регрессия градиентным спуском + график + кривая обучения.
3. Парабола `Y = a0 + a1*x + a2*x^2` обоими способами + кривые обучения.
4. Сравнение моделей на общем графике и по MSE.

Результаты: прямая `Y^ = -0.183 + 0.668*x` (MSE 0.0177),
парабола `Y^ = -1.017 + 3.213*x - 1.820*x^2` (MSE 0.0152) —
зависимость нелинейная, парабола точнее. Спуск сошелся к формулам.

## ТК 3-4. Классификация вин (winequality-red)

Задание: считать вино хорошим при `quality >= 7`, построить бинарный
классификатор, применить к неизвестным винам, посчитать Accuracy, Precision,
Recall, вывести confusion matrix. Результат — уравнение гиперповерхности,
отделяющей классы.

Что сделано:
- `train_test_split` (stratify, 80/20) + `StandardScaler` + `LogisticRegression`.
- Уравнение гиперплоскости `w·z + b = 0` (веса по всем 11 признакам).
- Метрики на тесте: Accuracy 0.894, Precision 0.696, Recall 0.372;
  confusion matrix `[[270, 7], [27, 16]]`.
- Классификация 5 неизвестных вин (класс + вероятность).

Низкий Recall объясняется дисбалансом: хороших вин всего 217 из 1599 (~13.6%).
